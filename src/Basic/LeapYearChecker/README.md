# 🗓️ Leap Year Checker

A simple C# console application that determines whether a given year is a leap year. This beginner-friendly project helps users understand basic input validation, conditional statements, and logical operators in C#.

### 🚀 Features  
✅ User-friendly console interface  
✅ Input validation to prevent invalid entries  
✅ Two methods to check for leap years (custom logic and built-in ```.IsLeapYear()```)  
✅ Colored output for better readability

### 🔧 How It Works

1. The program prompts the user to enter a year.
2. It validates the input to ensure it's a valid integer.
3. It determines whether the year is a leap year using logical conditions.
4. The result is displayed with color-coded output.
