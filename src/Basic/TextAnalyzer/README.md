# TextAnalyzer 📝🔍

A beginner-friendly **C# Console Application** that reads and analyzes the contents of a ```.txt``` file. This tool provides insights into the text by counting words, characters, identifying the longest and shortest words, and tracking word occurrences.

### ✨ Features

- 📄 Reads text from a .txt file.
- 🔢 Counts the total number of words and characters (with and without spaces).
- 📏 Identifies the longest and shortest words (case-insensitive and without duplicates).
- 📊 Displays word frequency (how many times each word appears).
- 🚀 Simple and easy-to-use console interface.

### 📂 How to Use

1. Run the application.
2. Enter the path to a valid .txt file.
3. The program will analyze the text and display the results.

### 🔧 Technologies Used

1. C# (.NET)
2. File Handling (System.IO)
3. LINQ for efficient text processing
