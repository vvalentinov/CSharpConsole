# Factorial Calculator

### 📌 Project Description 

This **Factorial Calculator** is a simple **C# console application** that calculates the factorial of a **non-negative integer** entered by the user. It includes **input validation, error handling**, and a user-friendly interface with colored warnings for invalid inputs.

### 🔹 Features  

✅ User Input Validation – Ensures the user enters a valid non-negative integer.  
✅ Error Handling – Displays an error message in red when an invalid input is provided.  
✅ Factorial Calculation – Uses a loop to compute the factorial efficiently.  
✅ Formatted Output – Displays a clean and structured result with separators.  

### ⚙️ How It Works

1️⃣ The user is prompted to enter a non-negative integer.  
2️⃣ If the input is invalid, the program displays an error and asks for input again.  
3️⃣ The factorial of the entered number is computed using an iterative loop.  
4️⃣ The result is displayed in a structured format.
