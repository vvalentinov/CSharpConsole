# 🔢 Prime Checker Project

This project is a simple yet powerful console application designed to determine whether a given number is a prime number.  
The user begins by entering a number, and the program first validates the input to ensure it is a valid integer.  
If the input is invalid, the program prompts the user to re-enter a valid number until correct input is provided.  
Once a valid number is entered, the program performs a thorough check to determine if it is prime, utilizing an efficient algorithm that only tests divisors up to the square root of the number.  
Finally, the program provides a clear and user-friendly output, indicating whether the entered number qualifies as a prime number or not.  
This tool combines input validation, mathematical logic, and user interaction to offer a seamless experience for prime number checking.

## 🛠️ Features:
- **Input Validation**  
    *Ensures the user enters a valid integer.*
- **Prime Number Logic**  
    *Efficiently checks for primality by testing divisors up to the square root of the number.*
- **Edge Case Handling**  
    *Handles cases where the number is less than or equal to 1, which are not prime numbers*
- **User-Friendly Output**  
    *Displays a clear message indicating whether the number is prime or not.*
